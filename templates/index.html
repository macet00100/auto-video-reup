Hướng Dẫn Triển Khai Chạy Miễn Phí Trên Cloud (24/7)

Bạn không cần treo máy tính tại nhà. Hãy triển khai hệ thống này lên Cloud Free theo các phương án dưới đây.

Phương án 1: Hugging Face Spaces (Khuyên Dùng) 16GB RAM Miễn Phí

Hugging Face cung cấp miễn phí môi trường Docker với 2 vCPU và 16GB RAM, cực kỳ lý tưởng để render FFmpeg mà không lo tràn RAM.

  1. Tạo tài khoản tại huggingface.co.
  2. Tạo một New Space, chọn SDK là Docker (Blank).
  3. Tải toàn bộ thư mục mã nguồn này lên repo Space đó (đã có sẵn file Dockerfile).
  4. Hugging Face sẽ tự động build và cung cấp link Web truy cập vĩnh viễn!
Phương án 2: Oracle Cloud Always Free VPS 24GB RAM 4 Core

Oracle tặng miễn phí trọn đời VPS cấu hình 4 OCPU ARM, 24GB RAM, 200GB SSD chạy Linux Ubuntu.

  1. Đăng ký Oracle Cloud Free Tier.
  2. Tạo máy ảo Ubuntu 22.04 (Ampere ARM).
  3. Cài đặt Docker: curl -fsSL https://get.docker.com | sh.
  4. Chạy ứng dụng: docker compose up -d để app chạy ngầm 24/7.
